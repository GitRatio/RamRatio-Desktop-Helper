## Choice and scope

RamRatio suspends eligible inactive tabs using Firefox's discard API. Waking a tab may reload its page; unsaved page state can be lost. Review protected sites and activity settings for your workflow. The optional helper supplies memory measurements; it is not an antivirus, remote-access tool, system cleaner, hardware repair tool, or guaranteed performance improvement.

You choose whether to install the helper, enable its setting, and grant Firefox permission. Update-notice acknowledgment records understanding of the notice; it does not authorize installation, grant system access, or enroll you in a service. You can continue using the extension without it and can disable/uninstall the helper at any time.
